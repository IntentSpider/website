https://github.com/intentspider/intentspiderengine


IntentSpider is built in C++ using the Standard Template Library. The current core is a personal intent graph engine rather than a pretrained neural language model or a cloud inference service. Its processes use graph algorithms, dynamic programming and ordinary data structures including vectors, sets and arrays. The core engine itself has no required network inference path, and its learned state can be serialized into a runtime snapshot. The public Research Preview is separate from that architecture and can use a shared remote state service around the WebAssembly build. The name IntentSpider came from the observation of spider-web behaviour described in the project history. More Information The first IntentSpider legacy version, also referred to in the paper, placed the system in a single main.cpp. The current repository separates the engine across C++ source and header files and includes the WebAssembly bridge used by the Research Preview. The project also keeps datasets and evaluation or demonstration files separately from the engine source, including earlier text corpora and later experiment resources.
