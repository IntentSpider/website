Git repositories and open source


The IntentSpider engine represents a completely new approach to predictive text, utilizing a dynamic, transient memory graph to capture textual tension and cadence. The core engine is open source and available for the public to inspect, modify, and build upon. You can explore the complete source code, mathematical foundations, and the WASM bridge directly in our GitHub repository, which hosts the raw C++ implementation of the webnet engine.


We encourage researchers, developers, and enthusiasts to dive into the codebase to better understand the algorithms powering IntentSpider. By open-sourcing the engine, we hope to foster a collaborative environment where the community can experiment with new dispersion mechanics, optimize the tensor operations, or adapt the architecture for entirely new predictive paradigms.





Open source licenses and 3rd party software that was contributed to the overall development of intent spider webnet engine

The core IntentSpider Webnet engine is written entirely from scratch in C++. After a thorough inspection of the C implementation, we can confirm that the engine operates without a single third-party open-source dependency or library. It relies exclusively on the standard C++ library (STL). The only external open-source tool utilized during the engine's development is the compiler toolchain used to port the C++ code to the web:


Emscripten (C++ to WebAssembly compiler) - https://emscripten.org/
