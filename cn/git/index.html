IntentSpider 使用 C++ 和标准模板库构建。当前核心是一个个人意图图引擎，而非预训练神经语言模型或云推理服务。其处理过程使用图算法、动态规划及包括向量、集合和数组在内的普通数据结构。核心引擎本身不需要网络推理路径，其学习到的状态可以序列化为运行时快照。公开的研究预览与该架构是分开的，并且可以围绕 WebAssembly 构建使用共享的远程状态服务。IntentSpider 这一名称源于项目历史中所描述的对蜘蛛网行为的观察。 更多信息 论文中也提到的第一个 IntentSpider 旧版将系统置于单个 main.cpp 文件中。当前仓库将引擎拆分到 C++ 源文件和头文件中，并包含研究预览使用的 WebAssembly 桥接代码。该项目还将数据集以及评估或演示文件与引擎源代码分开保存，包括较早的文本语料库和后续的实验资源。
