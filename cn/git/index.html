IntentSpider Engine GitHub 仓库

IntentSpider 使用 C++ 和标准模板库构建。它与 Google Gboard、Microsoft SwiftKey、Apple QuickType 和 Samsung Keyboard 常见的 n-gram 路线不同。IntentSpider 是面向设备本地执行的引擎。运行时快照不要求网络输入或网络输出。系统本身并不建立在自然语言处理技术或人工智能模型之上。主要过程来自图算法、动态规划、向量、集合、数组和一般数据结构。

这些算法经过数月设计和迭代。研究重点是理解复杂的人类表达模式和词语连接如何改变其他连接、向量和系统状态。IntentSpider 这个名字来自研究早期对自然界蜘蛛网行为的观察。完整背景可以在中文随笔中阅读。

最早的 IntentSpider Legacy 版本在论文中也有提到。当时整个系统放在一个 main.cpp 文件中。后来代码被拆分成多个源文件和头文件，逐步形成现在 Git 仓库中的结构。源代码目录包含 C++ 文件和头文件。仓库也保留了项目不同阶段使用的数据集和测试资料，其中包括早期测试阶段使用的 Project Gutenberg 文本。版本 1 已经不再依赖这些早期文本。编译后的 intentspider.exe 也包含在项目资料中。
